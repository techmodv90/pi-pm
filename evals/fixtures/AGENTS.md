# Project conventions for agents

This project keeps its conventions as installed skills under `.pi/skills/`.
Before writing any project file — especially documentation such as ADRs,
glossaries, or CONTEXT files — check whether a skill covers it, and if so
load that skill's full SKILL.md with your read tool (not cat or grep)
first and follow its conventions.

Terminology questions (what to call a thing, whether two terms conflict,
whether wording drifted from the spec) are answered by the skills, not by
grepping the code: read the covering skill's full SKILL.md first.
