# Minimize Regret

Optimize for what you will regret NOT having done.

## Process

1. Imagine yourself at the end (career, project, system lifetime) looking back.
2. Ask: which option would I regret not having taken?
3. Choose the option that minimizes future regret.

Use for long-horizon choices where short-term metrics mislead (architecture bets, skill investment, team structure).
