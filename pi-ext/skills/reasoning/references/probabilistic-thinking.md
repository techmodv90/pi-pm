# Probabilistic Thinking

Reason in probabilities, not certainties.

## Process

1. **List** all possible outcomes.
2. **Assign** a probability to each (must sum to 100%).
3. **Assess** the expected value of each option.
4. **Decide** on expected value, not on the best case.

Guard: base rates beat intuition — anchor percentages on observed frequency when any data exists.
