# Map vs Territory

The model is not the reality. Every model is a simplification; find where it
diverges.

## Process

1. **Identify** the model/map in use (docs, plan, mental model, dashboard).
2. Ask: where might it differ from reality?
3. **Seek** direct evidence from the territory (real data, actual behavior, running code).
4. **Adjust** the map where it diverged.
5. Remember: every model is a simplification — never treat the map as authoritative over observed reality.
