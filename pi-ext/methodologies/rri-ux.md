# RRI-UX — Experience Critique

RRI-UX critiques a proposed user experience before implementation. Use RRI requirements, user flows, wireframes/designs, and business rules.

## 5 UX Personas

First-Timer, Daily User, Power User, Reluctant User, Accessibility User.

## 7 UX Dimensions

Discoverability, Learnability, Efficiency, Error Prevention, Recovery, Satisfaction, Consistency.

## 8 Flow Physics Axes

FRICTION, COGNITIVE LOAD, INTERRUPTION, DEAD ENDS, SPEED BUMPS, ANXIETY, FRUSTRATION, DELIGHT.

Walk each relevant primary and edge flow through risk-relevant persona × dimension × axis combinations. Do not produce a meaningless full Cartesian product; state why omitted combinations are N/A.

Record findings with severity, persona, dimension, axis, flow step, evidence, affected REQ-ID, and smallest design correction. Inaccessible flows, dead ends, unrecoverable destructive actions, and failures of a primary user goal block owner design approval. Feed accepted corrections into Blueprint/Contracts before implementation.
